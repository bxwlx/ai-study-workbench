# AI 学习工作台（开源骨架）

一个**零依赖、离线可用**的个人学习工作台：单文件 HTML + 一份 JSONP 内容包。骨架只做「任务驱动」——每日四段单元、打卡、顺延、余量预警、资料库入口、AI 辅助；**内容全部来自可替换的主题包**，换领域不用改代码。

> 通俗说：这是一个「学习驾驶舱」。你今天该学什么、学到哪、落没落下——打开就知道。

## 特性

- **单文件即用**：`工作台.html` + `content.js` 放同一文件夹，双击打开即可（零 CDN、零框架、零构建、断网可用）
- **任务型不是内容型**：每日任务卡（学/练/记/测 四段可勾选）→ 自动打卡 + 模块推进；昨天没完成的自动顺延标红
- **按日期匹配**：首页永远显示「今天」该读的那一篇，不做假推送承诺
- **主题包机制**：`theme` + `modules/daily/manuals/prompts/glossary/tutorials/platforms` 七槽，换领域 = 换 `content.js`（规范见 `theme-schema.md`）
- **双模式**：本机双击 = 直跳本地资料文件；部署到公网/打包 APP = 应用内直接阅读资料正文
- **AI 辅助（可选）**：内置「AI 学习教练」——填你自己的 API Key 即可（OpenAI 兼容，DeepSeek 开箱即用，也支持本地 Ollama）；系统提示词可编辑，约束模型只基于你的资料回答
- **数据本地**：进度/打卡/收藏存浏览器 localStorage，可导出/导入备份

## 快速开始（1 分钟）

1. 下载 `工作台.html` 和任意一份 `content.js`（示例包或空白模板）到同一个文件夹
2. 双击 `工作台.html`
3. 首页开始勾「今日任务」四段；学习页看模块；我的页做备份

## 做你自己的主题包（换领域）

1. 复制 `content.blank.js` 为 `content.js`，按注释填写 `theme` 与 `modules`（阶段/模块/目标/任务）
2. 用内容生成提示词（README 下方）让 AI 生成 14 天 `daily` 内容
3. 资料多的领域：把手册/教程正文放资料目录，`file` 填相对路径，页面就能直达阅读

### 用 AI 生成每日内容（建议流程）

```
1. 选题：把阶段与模块清单交给 DeepSeek/Claude，让它输出「未来 7 天每日主题」表
2. 生成：对每个主题让它按 content.daily 结构输出 JSON（5-7 小节 + 3 道自测）
3. 核查：时效信息（价格/版本/规则）单独跑一轮事实核查，标注核实日期
4. 入库：粘贴进 content.js → version +1 → 刷新
```

> 提示词模板示例（每天 1 篇、口语化、末节「今天怎么验收」、quiz 能用正文回答、禁编造来源）——已沉淀为可直接复制的套件，欢迎借鉴结构。

## 文件结构

```

content.blank.js     空白模板（做新主题从这里开始）
theme-schema.md      主题包字段规范
```

**快速体验**：下载 `工作台.html` + `content.example-ai.js` → 把示例改名为 `content.js` → 双击打开。
